# Implications of digital technologies — IGCSE ICT

Interactive lesson for Pearson Edexcel International GCSE ICT, **Unit 3 Operating online, Chapter 9 Implications of digital technologies** (book pages 147–158). Only these pages are covered.

Each section is explained step by step with interactive simulations, followed by the book's **activities** and a short auto-marked **✓ Check**. Each part ends with a **test** (multiple choice + exam-style questions with mark schemes, including all the chapter questions on page 158).

**Part A · Data protection and copyright** (pages 147–150)

1. Data protection — Singapore's Personal Data Protection Act (consent), the UK data protection principles, rights of individuals → Activities (Comparing data protection law, Data protection in your country) → ✓ Check
2. Data across borders — the EEA, international agreements, the EU–US Privacy Shield Framework (with an update note on the 2023 Data Privacy Framework) → Activity (The Privacy Shield Framework) → ✓ Check
3. Copyright — © notice (Figure 9.1), laws and agreements, paid licences, open source and a Creative Commons licence builder → Activity (Creative Commons licences) → ✓ Check
4. Fair use, DRM and geoblocking (Figure 9.2) → ✓ Check
5. Test Part A (chapter questions 2, 4, 6, 10)

**Part B · Monitoring, sustainability, health and safety** (pages 150–157)

6. Monitoring movements — a data trail (CCTV, ANPR, cards, IP/MAC, GPS, friend finder with consent), benefits and drawbacks → Activities (Anti surveillance clothing, Monitoring people's location) → ✓ Check
7. Monitoring communications — parental control, providers' records, Investigatory Powers Act 2016 (Figure 9.5), privacy vs protection → ✓ Check
8. Sustainability issues — data centre builder, e-waste, Table 9.1 → Activity (Reducing the environmental impact) → ✓ Check
9. Health and safety — spot the risks (Table 9.2), good posture (Figures 9.7–9.8) → Activities (Digital devices and personal safety, Using sockets safely) → ✓ Check
10. AI and responsibility — self-driving car, reaction-time test, dilemmas → Activity (Using autopilot) → ✓ Check
11. Test Part B (chapter questions 1, 3, 5, 7, 8, 9, 11, 12) · Key terms (searchable)

**Progress** is saved in the browser (`localStorage`, key `im-progress-v1`); **My progress** copies a report or a progress code (`IM1Z.…`) to carry on with another device. Nothing is sent to a server. People, companies and places in the simulations are made up. Sound only plays after a click.

**Controls:** Play/Pause (Space), Next (→), Back (←), Restart scene (R), Projector mode (P), Full screen (F). Each scene has its own URL, e.g. `#health` or `#check-ai`.

Visual style: British School Alzira · Xàtiva · Gandia (BS Format: navy, school blue, yellow step markers). Plain HTML, CSS and JavaScript — no build step.
